# Тестирование в продакшене

[![hexlet-check](https://github.com/le-victoria22/qa-engineer-project-85/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/le-victoria22/qa-engineer-project-85/actions)

Проект тестирования open-source платформы для соревнований по программированию в реальном времени — **Codebattle** https://codebattle.hexlet.io/

**Codebattle** — это многопользовательская онлайн-игра с открытым исходным кодом, разрабатываемая сообществом Хекслета. Главная цель платформы — дать двум игрокам возможность соревноваться в решении задач, наблюдая за написанием кода друг друга в реальном времени. 

## Источники требований

Поскольку Codebattle развивается сообществом без единого формального технического задания, список требований к продукту был восстановлен из следующих источников:

- *Базовые требования из задания к данному проекту* — общие нефункциональные стандарты качества (безопасность, производительность, адаптивность, кроссбраузерность).
- *Официальная Wiki-документация репозитория Codebattle* (https://github.com/hexlet-codebattle/codebattle/wiki) — разделы «Механика игры» и «News Feed» (бизнес-логика, жизненный цикл битвы, роли пользователей).
- *Исследовательское тестирование живого приложения* — анализ актуального пользовательского интерфейса и сценариев поведения системы в продакшене.
- *Исторический обзор проекта* (Статья на Хабре https://habr.com/ru/companies/hexlet/articles/268389/) — использована для понимания изначальной концепции и целей создания игры.

## Структура проекта

- requirements.yml - функциональные, нефункциональные и неявные требования к системе
- test-cases.yml - подробные тест-кейсы для проведения тестирования
- testing-report.yml - отчет о результатах прохождения тестирования по подготовленным тест-кейсам (со статусами выполнения `pass` / `fail`)
